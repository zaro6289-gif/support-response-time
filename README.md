# support-response-time
Анализ времени решения задач службы поддержки

Задача: понять, почему задачи в трекере поддержки решаются долго и от чего зависит время решения.

Весь анализ лежит в ноутбуке аналитика.ipynb.

Данные
issues.csv: выгрузка задач из трекера, 66 691 задача, 58 полей (тип, приоритет, статус, исполнитель, даты создания и закрытия, этапы workflow)
Источник: [укажите: Kaggle / курс / другое]
Что сделано

Подготовка данных: привела даты к формату datetime, рассчитала время решения в часах.

Очистка: убрала некорректные и аномальные значения (оставила задачи со временем решения от 0 до 720 ч, то есть до 30 дней). Для анализа осталось 19 902 задачи.

Описательная статистика: среднее время решения 176,5 ч, медиана 113,8 ч. Среднее завышено выбросами, поэтому медиана лучше отражает типичную задачу.
SQL-анализ: сравнила время решения по приоритетам, типам задач и часу создания.

Визуализация: дашборд из 4 графиков: распределение времени решения, boxplot по типам, сравнение приоритетов, нагрузка по часам.
